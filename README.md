# My FPS Game

A first-person shooter built in Python using the Ursina engine.
Made as a learning project, one feature at a time.

## Features (roadmap)
- [ ] Walk around a 3D room (WASD + mouse)
- [ ] Shoot with a gun
- [ ] Enemies that take damage
- [ ] Score and health bar
- [ ] Custom map and boss fight

## Run it
1. `pip install ursina`
2. `python game.py`
